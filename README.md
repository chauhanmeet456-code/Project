# Frontend Projects Collection

A collection of beginner-friendly **HTML, CSS, and JavaScript projects** created for practicing frontend web development.

## 🚀 Live Demo

👉 **[View the Live Website](https://chauhanmeet456-code.github.io/Project/)**

## 📂 Projects Included

| Project | Description |
|---|---|
| 🧮 **Calculator** | A simple calculator built with HTML, CSS and JavaScript. |
| 📅 **Calendar** | A web-based calendar interface. |
| 💱 **Currency** | A currency-related web project for practicing JavaScript and UI development. |
| 🔐 **Login Page** | A responsive login page design. |
| 🎬 **Movie Project** | A movie-themed frontend project. |
| 📝 **Registrations** | A registration/form-based web project. |
| 🌤️ **Weather** | A weather interface for displaying weather information. |

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Interactivity and functionality
- **Git & GitHub** — Version control and deployment
- **GitHub Pages** — Live hosting

## ▶️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/chauhanmeet456-code/Project.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use **VS Code with Live Server** for easier development.
